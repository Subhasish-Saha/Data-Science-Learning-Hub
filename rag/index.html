Good to know

  • Progress is saved per device. The tracker stores your status in each browser's local storage, so your phone and laptop track separately — it does not sync across devices (that would need a backend).
  • Works offline-ish. Fonts and code syntax-highlighting load from a CDN; without internet the pages still render, just with fallback fonts and un-colored code.
  • Save as PDF. Open the "Complete edition" and use your browser's Print → Save as PDF for an offline copy.
