⚠ API currency — verified August 2026

LangChain 1.0 gutted the langchain package. Current: LangChain 1.3.14 · langchain-core ≥ 0.3.81 · Python 3.10–3.14.

  • LLMChain, ConversationChain, AgentExecutor, ConversationBufferMemory, MultiQueryRetriever, the indexing API and hub all moved to langchain-classic.
  • Agents run on the LangGraph runtime via create_agent + middleware; AgentExecutor and create_react_agent are deprecated.
  • Messages gained standard content blocks; .text is now a property.
  • Memory is three deprecations deep — the current answer is LangGraph persistence.

Nearly every course from 2023–24 teaches imports that no longer live where they say. Always cross-check reference.langchain.com and the v1 migration guide.
