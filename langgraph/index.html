⚠ API currency — August 2026

LangChain and LangGraph hit 1.0 LTS in October 2025. This resource is written against v1:

  • AgentExecutor, initialize_agent, and langgraph.prebuilt.create_react_agent are deprecated.
  • The current prebuilt entry point is from langchain.agents import create_agent, which runs on the LangGraph runtime.
  • LangGraph is the runtime; LangChain is the layer on top — "LangGraph vs LangChain" is a layering question, not a rivalry.
  • All LangChain packages require Python 3.10+.

Any tutorial from 2023–24 using AgentExecutor is teaching deprecated syntax. Always cross-check docs.langchain.com.
