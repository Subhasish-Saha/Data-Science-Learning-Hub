⚠ API currency — verified August 2026

Both libraries hit 1.0 on 22 Oct 2025, with a commitment to no breaking changes until 2.0. Written against the current releases:

  • LangChain 1.3.15 and LangGraph 1.2.11 (both 11 Aug 2026) · Python ≥ 3.10.
  • AgentExecutor, initialize_agent, and langgraph.prebuilt.create_react_agent are deprecated. The current prebuilt entry point is from langchain.agents import create_agent, which runs on the LangGraph runtime.
  • LangGraph is the runtime; LangChain is the layer on top — "LangGraph vs LangChain" is a layering question, not a rivalry.

Covered post-1.0 additions: LangGraph 1.2's per-node timeouts and error handlers (Saga compensation), set_node_defaults, DeltaChannel, and the v3 streaming API; LangChain 1.1–1.3's model profiles, built-in middleware (summarization, model-retry, moderation), tool extras, and ProviderStrategy; plus LangSmith's composite and thread/multi-turn evaluators. LangGraph 1.2.10–1.2.11 added the typed v3 stream_events return with native projections and per-node trace_policy on add_node.

Any tutorial from 2023–24 using AgentExecutor is teaching deprecated syntax. Always cross-check docs.langchain.com.
