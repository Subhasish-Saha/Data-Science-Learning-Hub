⚠ Library currency — verified August 2026

scikit-learn 1.9.0 (2 Jun 2026, Python ≥ 3.11) · XGBoost 3.4.1 · LightGBM 4.7.0 · CatBoost 1.2.10.

  • Metadata routing (set_config(enable_metadata_routing=True), set_fit_request) is how sample_weight travels through a Pipeline and cross-validation. Saying “sklearn can't do that, so I write a manual fold loop” describes a library from several versions ago.
  • scikit-learn 1.8 added free-threaded CPython support (3.14 wheels) — the GIL is no longer automatically your parallelism ceiling.
  • The tabular consensus moved. “GBDTs beat deep learning on tabular data” is now genuinely contested for small-to-medium data by TabPFN-3, which scales to 1M rows and reports beating 8-hour-tuned GBDT baselines on TabArena. Caveat it properly: pretrained purely on synthetic data, with a thinner ops story.
  • Calibration is no longer automatic advice. A recent benchmark found Platt and isotonic can degrade proper-scoring performance for strong tabular models, with Venn-Abers best on average — so calibrate on held-out data and measure whether it helped.

Every part carries a provenance note distinguishing what was verified against primary sources from what is directional. Treat any benchmark ranking or “current best model” claim as stale on sight and re-benchmark on your own data.
